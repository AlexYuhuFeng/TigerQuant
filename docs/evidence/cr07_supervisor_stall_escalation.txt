TigerQuant CR-07/CR-09 evidence - a hung supervisor stops the system, not just the console
Generated: see the git commit this file was added in

===========================================================================
1. The gap this closes
===========================================================================
Named as a limitation in `docs/evidence/cr09_hang_detection.txt`: *"A hang is not escalated. The verdict
is printed; no alert is raised, and nothing halts. CR-07's watchdog is the right owner and does not
consult this yet."*

**A HANG NOBODY IS ALERTED TO IS HALF A FEATURE.** The watchdog's whole purpose is to stop the system
when something is wrong, and a frozen supervisor cannot reconcile -- which ADR-0008 says must complete
before a restart permits new exposure.

===========================================================================
2. The design decision
===========================================================================
**THE WATCHDOG TAKES A VERDICT, NOT A PATH.** It is a deterministic evaluator that "reads metrics and
conditions, never prose", and reading a file is a side effect. The caller detects and passes the
verdict; the watchdog judges it.

That keeps the layer boundary intact and lets the tests run with NO heartbeat on disk -- which matters
here, because the sandbox cannot create temp directories, so a test needing one is verified only by CI.

===========================================================================
3. Severity, conservative in the right direction
===========================================================================
    HUNG     -> CRITICAL   halts new exposure, which is the safe default
    STALE    -> WARNING    an absent heartbeat is a FIRST RUN as easily as a fault
    UNKNOWN  -> WARNING    visible and unexplained
    healthy  -> nothing    a watchdog that flags normal operation gets ignored

**`None` MEANS NO CHECK WAS PERFORMED**, deliberately different from a verdict of `STALE`. Not looking
is not the same as looking and finding nothing, and collapsing them would let an unchecked system report
as checked. Asserted, including that a caller passing no verdict is unaffected -- the parameter defaults
to `None`, so every existing call site keeps its behaviour.

A NEW `ReasonCode.SUPERVISOR_STALLED`, because none of the 41 existing codes covered a stalled
component. It names a STALL rather than a crash: a hung process may still hold a broker connection, and
treating it as absent would be wrong about what a responder is dealing with.

CONDITIONS COMPOSE: a stalled supervisor AND an unreconciled account are both reported, and `engage`
actually consumes the verdicts. A verdict the halting path cannot consume is not an escalation.

===========================================================================
4. Limitations
===========================================================================
1. **The watchdog only sees a verdict if a CALLER passes one**, and nothing reads the heartbeat on a
   schedule. A hang is still noticed when somebody next inspects or restarts, NOT when it happens.
2. The 900-second bound is judgement, not measurement.
3. No alert is raised -- the verdict reaches the halt path, and nothing pages anybody.
